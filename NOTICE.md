# Notices and acknowledgements

NJC AI Monitor is an independent Windows/C# rewrite based primarily on
[beret21/MacTR](https://github.com/beret21/MacTR), an MIT-licensed macOS application for
Thermalright LCD devices.

Early AI-agent monitoring concepts were inspired by the
`m1ng-li/mac-thermalright-ai-monitor` community fork. NJC AI Monitor does not use that
repository as its release remote or product identity.

The Windows application, 1920×400 five-column interface, dynamic panel selection,
market/news/weather integrations, agent-session tracking, completion notifications, and
Windows packaging were independently implemented for NJC AI Monitor.

The LY USB protocol implementation was also informed by the public reverse-engineering work in
[thermalright-trcc-linux](https://github.com/Lexonight1/thermalright-trcc-linux).

Third-party library and service notices are listed in `Windows/THIRD_PARTY_NOTICES.md` in
the source repository and in `THIRD_PARTY_NOTICES.md` beside this file in release archives.
